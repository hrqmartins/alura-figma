# 💸 FINZ – Organização Financeira com Praticidade

[![FINZ BANNER](https://i.postimg.cc/0yGBKBsg/banneroxo.jpg)](https://postimg.cc/ZWRc1jnj)

✨ **Projeto desenvolvido no curso da [Alura](https://www.alura.com.br/)** com foco em **design de interface (UI)** utilizando o **Figma**.

---

## 📌 Sobre o Projeto

O **FINZ** é uma proposta de aplicativo de controle financeiro que visa trazer **clareza**, **planejamento inteligente** e **automação** para o dia a dia das pessoas. A interface foi pensada para ser moderna, intuitiva e acessível para todos os perfis de usuários.

---

## 🛠️ Tecnologias e Ferramentas

- 🎨 **Figma** – Ferramenta principal para o design de interface.
- 🧠 Princípios de UX/UI aplicados.
- 🖌️ Inspiração em apps reais de fintechs.

---

## 🔍 Funcionalidades Apresentadas

✅ Visualização de saldos bancários  
✅ Planejamento financeiro com orçamentos  
✅ Automatização de categorias de gastos  
✅ Estatísticas de uso e impacto positivo  

---

## 🚀 Etapas do Projeto

1️⃣ **Abertura da conta** – Design da tela de cadastro e início da jornada  
2️⃣ **Conexão com bancos** – Interface simples para sincronizar instituições financeiras  
3️⃣ **Acompanhamento financeiro** – Dashboard com insights, categorias e gráficos
